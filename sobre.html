Sobre o CarZone

O CarZone é um projeto criado para reunir informações sobre diferentes tipos de carros em um só lugar.

Nosso objetivo

O objetivo do CarZone é facilitar a descoberta de novos carros, permitindo que os usuários conheçam modelos, categorias e diferentes características.

O que você pode fazer

No CarZone você pode explorar carros, conhecer diferentes categorias e comparar modelos para entender melhor suas características.

Tecnologias utilizadas

Este projeto utiliza tecnologias fundamentais do desenvolvimento web:

  • HTML — estrutura das páginas
  • CSS — aparência e design
  • JavaScript — interações e funcionalidades
